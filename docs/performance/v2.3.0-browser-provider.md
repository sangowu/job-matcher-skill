# v2.3.0 Browser Provider 本地小型基准

记录时间：2026-08-25（Europe/Dublin）。当前为未提交工作树，基于 `2fc388958c665c6cb1c97e6f5cc92dcdc463a43d`。

## 方法

- 与 v2.2.0 基线相同：15 个合成职位，`merge -> update -> render`，2 次预热，10 次冷隔离迭代。
- 每次验证 15 个职位全部 merge、update 和 render，外部调用为 0。
- 新增 Fake Provider 项：并发 2，每次迭代 10 个会话，每会话 7 个带 PII-safe 指标写入的动作，共 70 个动作。
- Windows 11，Python 3.13.5。绝对耗时受本机抖动影响，重点看输出完整性和 p50/p95 回归。
