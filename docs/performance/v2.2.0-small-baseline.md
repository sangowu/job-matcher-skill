# Job Matcher v2.2.0 小数据性能基线

状态：实现前基线。

## 测量范围

- Commit：`2fc388958c665c6cb1c97e6f5cc92dcdc463a43d`
- 环境：Windows 11，Python 3.13.5
- 数据：15 个合成职位
- 流程：`merge -> update -> render`
- 缓存：每次迭代使用隔离的冷数据目录
- 迭代：2 次预热，10 次记录
- 外部调用：0（无 Web Search、ATS、远程浏览器或 LLM）

本基线只测确定性核心管道，不代表完整职位搜索的端到端耗时。后续版本必须使用相同数据规模、缓存状态和运行环境进行对比。
